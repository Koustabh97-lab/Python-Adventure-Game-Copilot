# 🗺️ Python Adventure Game (Built with GitHub Copilot)

## 📌 Overview
This repository contains a text-based adventure game developed in Python. The objective of this project was to practice writing functions, handling conditionals (if-else), managing user inputs, and utilizing loops to create an interactive command-line experience. 

This project was developed with the assistance of **GitHub Copilot** to explore AI-assisted coding, write more efficient functions, and speed up the development process.

## 🛠️ Technologies Used
* **Language:** Python 3
* **Tools:** VS Code
* **AI Assistant:** GitHub Copilot
* **Core Concepts:** Functions, While Loops, If-Else Statements, Input Handling.

## 🎮 Game Features
* **Interactive Storyline:** Players act as an explorer searching for legendary treasure.
* **Decision-Based Gameplay:** The game branches into different scenarios based on user choices (e.g., choosing between a forest or a cave).
* **Multiple Outcomes:** Strategic decisions lead to different paths and ultimate outcomes (Winning, Losing).
* **Replayability:** A continuous loop allows players to restart the game easily after finishing or failing.
